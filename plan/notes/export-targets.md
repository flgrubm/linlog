# Research notes: proof export targets and candidate crates

Gathered on 2026-09-29 from the sources named below. Facts, not decisions;
the steps that use them verify against the live sources.

## Click & coLLecT (the reference implementation)

Repository: github.com/ComputerAidedLL/click-and-collect (OCaml, LGPL-2.1).
Files: `proof.ml`, `rule_request.ml`, `raw_sequent.ml`, `sequent.ml`,
`export_as_coq.ml`, `export_as_latex.ml`, `proof_transformation.ml`,
`focused_proof.ml`, `auto_prove_sequent.ml`, and `nanoyalla/` (the Rocq kernel
it certifies against).

**Proof type** (`proof.ml`): a tree with one constructor per one-sided rule,
each carrying the split context so the conclusion is reconstructible:
`Axiom_proof`, `One_proof`, `Top_proof`, `Bottom_proof`, `Tensor_proof`,
`Par_proof`, `With_proof`, `Plus_left_proof`, `Plus_right_proof`,
`Promotion_proof`, `Dereliction_proof`, `Weakening_proof`,
`Contraction_proof`, `Exchange_proof` (explicit permutation), `Cut_proof`,
`Unfold_litt_proof`, `Unfold_dual_proof`, `Hypothesis_proof` (open leaf).
Sequents are ordered lists, so exchange is explicit.

**JSON** (`proof.ml` `to_json`/`from_json`):
```json
{"sequent": {"hyp": [], "cons": [formula, ...]},
 "appliedRule": null | {"ruleRequest": {"rule": "tensor", "formulaPosition": 1},
                        "premises": [proof, ...]}}
```
Formulas: `{"type":"litt","value":"x"}`, `{"type":"one"}`,
`{"type":"dual","value":f}`, `{"type":"tensor","value1":f,"value2":f}`, with
types `litt dual tensor par with plus one bottom top zero ofcourse whynot
lollipop`. Rules: `axiom one bottom top zero tensor par with plus_left
plus_right promotion dereliction weakening contraction exchange cut
unfold_litt unfold_dual`. Verbose by design (a web UI edits it); linlog's
format is the compact term of decision D6, with this shape as an optional
interchange export if ever needed.

**LaTeX export** (`export_as_latex.ml`): `\usepackage{amssymb,cmll}` and
`\usepackage{ebproof}`; one macro per rule, e.g.
`\newcommand*{\axv}[1]{\infer{0}[\ensuremath{\mathit{ax}}]{\vdash #1}}`,
`\tensorv` = `\infer{2}[\otimes]`, `\parrv` = `\infer{1}[\parr]`,
`\hypv` = `\hypo{\vdash #1}`; the tree is emitted postfix inside
`\begin{prooftree} … \end{prooftree}`.

**Coq export** (`export_as_coq.ml`): the generated file is
```coq
(* generated *)
From NanoYalla Require Import macrollcut.
Import LLNotations.
Section TheProof.
Variable a b : formula.
Goal ll [ <conclusion> ].
Proof.
  apply (tens_r_ext [head]); cbn_sequent. { ... } { ... }
Qed.
End TheProof.
```
One `apply (<rule>_ext <context>); cbn_sequent.` per rule: `ax_expansion`
(axiom on any formula), `one_r_ext`, `top_r_ext`, `bot_r_ext`, `tens_r_ext`,
`parr_r_ext`, `with_r_ext`, `plus_r1_ext`/`plus_r2_ext`, `oc_r_ext`,
`de_r_ext`, `wk_r_ext`, `co_r_ext`, `ex_perm_r <perm> <list>`, `cut_r_ext`.
Defined in `nanoyalla/macroll.v`. NanoYalla 1.1.3 needs Coq ≥ 8.10 and builds
either standalone (cut as an axiom, `axiomcut.v`) or on Yalla (`yallacut.v`).

## Yalla (github.com/olaure01/yalla, LGPL-3.0)

Latest v2.1.0, tested with Rocq 9.2, needs OLlibs v2.1. `yalla/ll_def.v`:
```coq
Record pfrag := mk_pfrag {
  pcut : formula -> bool;
  pgax : { ptypgax : Type & ptypgax -> list formula };
  pmix : nat -> bool;
  pperm : bool }.
Inductive ll P : list formula -> Type :=
| ax_r X : ll P (covar X :: var X :: nil)
| ex_r l1 l2 : ll P l1 -> PCPermutationT (pperm P) l1 l2 -> ll P l2
| ex_wn_r l1 lw lw' l2 : ll P (l1 ++ map wn lw ++ l2) -> PermutationT lw lw' -> ll P (l1 ++ map wn lw' ++ l2)
| mix_r L (f : pmix P (length L)) : ForallT (ll P) L -> ll P (concat L)
| one_r : ll P (one :: nil)
| bot_r l : ll P l -> ll P (bot :: l)
| tens_r A B l1 l2 : ll P (A :: l1) -> ll P (B :: l2) -> ll P (tens A B :: l2 ++ l1)
| parr_r A B l : ll P (A :: B :: l) -> ll P (parr A B :: l)
| top_r l : ll P (top :: l)
| plus_r1 A B l : ll P (A :: l) -> ll P (aplus A B :: l)
| plus_r2 A B l : ll P (A :: l) -> ll P (aplus B A :: l)
| with_r A B l : ll P (A :: l) -> ll P (B :: l) -> ll P (awith A B :: l)
| oc_r A l : ll P (A :: map wn l) -> ll P (oc A :: map wn l)
| de_r A l : ll P (A :: l) -> ll P (wn A :: l)
| wk_r A l : ll P l -> ll P (wn A :: l)
| co_r A l : ll P (wn A :: wn A :: l) -> ll P (wn A :: l)
| cut_r A (f : pcut P A = true) l1 l2 : ll P (dual A :: l1) -> ll P (A :: l2) -> ll P (l2 ++ l1)
| gax_r a : ll P (projT2 (pgax P) a).
```
The principal formula is at the head; `tens_r` concludes `l2 ++ l1`. Fragments
are restrictions in `ll_fragments.v`; ILL is a separate development in the
same repository. `microyalla/` ships `nanoll.v` and `microll.v` as kernel
libraries "for certifying proofs generated by automatic provers", with
embeddings into full Yalla.

**Lean and Agda.** github.com/FormalizedFormalLogic/LinearLogic (Lean 4,
Apache-2.0) has one-sided calculi over `Multiset Formula` without units in the
fetched excerpt, is early-stage with cut elimination in an open PR; nothing in
Mathlib. Agda has ncill (non-commutative ILL) and course material, no
maintained classical-LL kernel. Rocq via NanoYalla/Yalla is the only mature
certificate target; Lean is a possible second target once that project
stabilises.

## LaTeX proof trees

- **ebproof** 2.1.1 (LPPL 1.3, expl3; ctan.org/pkg/ebproof) is what Click &
  coLLecT emits. Syntax `\infer<n>[label]{conclusion}` in postfix order:
  ```latex
  \begin{prooftree}
  \hypo{ \Gamma, A &\vdash B }
  \infer1[abs]{ \Gamma &\vdash A\to B }
  \hypo{ \Gamma \vdash A }
  \infer2[app]{ \Gamma \vdash B }
  \end{prooftree}
  ```
  `\infer0[ax]{…}` for axioms; `&` aligns turnstiles; options `left label=`,
  `dashed`, `double`. The linear-logic symbols come from `cmll` (`\parr`,
  `\with`, `\oc`, `\wn`) or `\otimes`, `\oplus`, `\multimap` from amssymb.
- **bussproofs** 1.1 (LPPL) is older and ubiquitous, supported by MathJax:
  `\AxiomC{}`, `\UnaryInfC{}`, `\BinaryInfC{}`, `\RightLabel{}`,
  `\DisplayProof`.
- **prooftrees** (CTAN) draws tableau trees, not derivations.

## Typst proof trees

- **curryst** 0.6.0 (MIT, 2025-11; typst.app/universe/package/curryst):
  `rule(name: [ax], $conclusion$)` for an axiom,
  `rule(name: $otimes$, premise1, premise2, conclusion)` otherwise (all but
  the last argument are premises, premises may be nested `rule`s),
  `#prooftree(tree)` to draw, with options `vertical-spacing`,
  `min-premise-spacing`, `title-inset`, `stroke`, `min-bar-height`, `dir`.
- The Typst package `prooftrees` is deprecated in favour of curryst.

## `lolli` (github.com/ibrahimcesar/lolli, MIT)

Educational Rust focused prover (pest parser, MLL/MALL/MELL, ASCII trees,
bussproofs and DOT output), self-described as exponential on large inputs,
not on crates.io. Nothing to reuse.
